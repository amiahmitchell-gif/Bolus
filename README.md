# Jackson's Bolus Calculator

A phone app (installable web app) that follows his care team's insulin bolus worksheet:
carbs ÷ carb ratio + (blood sugar − target) ÷ correction factor, rounded with the ½-unit rules.
It also enforces the 3-hour gap between fast-acting doses, flags lows, and keeps a log with food trends.

This helps with the math. It does not replace his care team.
